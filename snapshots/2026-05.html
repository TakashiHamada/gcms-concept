01主要コンポーネント

実装は 2 つの GAS パッケージ と 2 つの Python ツール から成ります。

Name Runtime Schedule
api-input GAS Web App on-demand (HTTP POST)
leave-tracker GAS 10 分 cron
daily-report Python (local) 毎朝 06:00 JST
ingest-meetings Python (local) 30 分 cron

api-input

GAS Web App

全書き込みを受け持つ 単一の窓口。 HTTP POST の body にある apiKey で認証し （GAS の doPost が HTTP ヘッダを読めない仕様の回避）、 OWNER_EMAIL impersonate で会社カレンダーへ upsert します。

  • · zod によるスキーマ検証
  • · extendedProperties.private の 1024 文字 fail-fast
  • · 冪等性判定（create / update / noop）

leave-tracker

GAS · 10 min

10 分おきに各社員の primary に手入力された 「有給」「有休」 イベントのタイトルと extProps を events.patch で更新します。 年度起算月を gcms.leave.periodStart で検出し、 累計 (N) を毎回ゼロから振り直します。

daily-report

Python · 06:00 JST

社員ごとに前日の完了 Google Tasks + primary calendar + 会社カレンダーを読み出し、 ローカル ollama で 1 セクションずつ日報を生成して、 会社カレンダーに 1 日 1 イベント（[日報] YYYY-MM-DD、終日）に集約します。

description は冒頭の ## 会社全体 セクション + 各社員 ## 表示名 セクションの並列構成で、 お休みの社員は LLM をスキップして - お休み (n) を決定論的に出力します。

ingest-meetings

Python · 30 min

30 分おきに Drive フォルダを polling し、Gemini Meet 議事録 Doc を ollama で圧縮、 会社カレンダーに 1 議事録 = 1 イベントを upsert します。

description は ＜概要＞（140 字以内）+ ＜次のステップ＞（担当者別）+ ＜詳細＞（タイムスタンプ削除済み）の 3 ブロック構造。

8000 字超過時の 3 段階フォールバック

  1. 1LLM による圧縮
  2. 2再圧縮
  3. 3＜詳細＞ 末尾の切り詰め

LLM プロンプトは 体言止め・常体・新事実生成禁止 を強制し、 gemma 系特有の末尾 postscript（--- + **【まとめ…】** + （※…））はサニタイザで除去します。

02集約データ仕様

現在、3 系統のデータが Stage 1 のパイプライン経由で会社カレンダーに集約されています。

  • 議事録

    ingest-meetings

    Gemini Meet で生成された議事録 Doc を Drive から取り込み、 ＜概要＞ / ＜次のステップ＞ / ＜詳細＞ の 3 ブロックに整形して 1 議事録 = 1 イベントに集約。プライベートな雑談や個人情報は LLM 段階でフィルタされます。

  • 日報

    daily-report

    前日の Google Tasks 完了分と各社員のカレンダーから、ローカル LLM が 1 セクションずつ生成。 [日報] YYYY-MM-DD という終日イベント 1 つに、会社全体と社員別の見出しで並べて集約。 休んでいる社員は LLM をスキップし、- お休み (n) と決定論的に記録します。

  • 有給休暇

    leave-tracker

    各社員が自分のカレンダーに書いた「有給」「有休」イベントを 10 分おきに集計し、 年度起算月から累計 (N) を毎回ゼロから振り直します。残数管理の単一情報源として機能します。

04設計上の核

Python ツールは Calendar API を直接叩かず、 必ず api-input 経由で書き込みます。 これにより、冪等性・スキーマ検証・サイズ制限が TypeScript 側 1 箇所に集約 され、 二重実装を回避しています。

Single write surface

Python tools  ─┐
GAS jobs      ─┼─→ api-input (zod / size / idempotency) ─→ Google Calendar
manual edits  ─┘
